# CHIPS Metrology Ontology

## Description

This is an ontology that describes the scientific projects funded by the CHIPS Metrology program. The base ontology is the PMDCo v2, which is based on Prov-O. 

## Roadmap
1. Possible refactoring into BFO-2020
